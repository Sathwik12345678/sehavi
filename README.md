# SeHaVi Foods 3D Frontend

A frontend-only Vite + React experience for SeHaVi Foods, featuring an interactive React Three Fiber hero, product catalogue, responsive layouts, product filtering, search, and cart interactions.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Product photography is loaded from the approved SeHaVi product image URLs. The 3D hero uses procedural package forms and grain geometry, so it needs no model downloads to render.
